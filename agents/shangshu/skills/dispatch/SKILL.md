# 六部派发路由表

根据任务类型，派发给对应部门的 subagent 执行。

## 部门路由

| 部门 | agent_id | 职责范围 | 典型任务 |
|------|----------|---------|---------|
| 工部 | gongbu   | 开发/架构/代码 | 功能开发、代码重构、技术方案实现、API 设计 |

## 派发规则

1. **单一职责优先**：一个任务尽量只派发给最匹配的一个部门
2. **可并行派发**：如果任务涉及多个部门职责，可同时派发多个 subagent
3. **格式统一**：派发时使用标准任务令格式：
   ```
   📮 尚书省·任务令
   任务ID: JJC-xxx
   任务: [具体内容]
   输出要求: [格式/标准]
   ```
4. **汇总返回**：收齐所有部门结果后统一汇总返回给中书省
